# bluff-landing

The public web page for Bluff: a short landing page and the privacy policy
(served with GitHub Pages). The game itself lives in a private repository.

Fonts: Bebas Neue and Inter, both under the SIL Open Font License 1.1
(licences in `fonts/`).

Versions: see [CHANGELOG.md](CHANGELOG.md). To release one, add its section,
set `<meta name="version">` in every page, commit, and tag it `vX.Y.Z`.
